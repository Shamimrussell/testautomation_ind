# Testautomation – Individuell uppgift (FSH)

Individuell uppgift i testautomation, del av utbildningen till IT-testspecialist på FransSchartau Handelsinstitut.

## Om projektet

Kombinerar API- och testautomation i Python (Pytest) med lasttestning i k6.

## Teknik

- Python, Pytest
- k6 (lasttestning)

## Struktur

- `k6/` – lasttester
- `src/` – källkod
- `tests/` – Pytest-tester
- `config.py` – konfiguration
- `conftest.py` – delade Pytest-fixtures

## Installation och köra tester

```
pip install -r requirements.txt
pytest
```
